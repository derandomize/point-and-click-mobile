# Стилистика

## Визуальный язык
- **Сеттинг:** уютный подземный город, освещённый лампами, грибами и свечами.
- **Стиль:** рисованная 2D-иллюстрация, тёплая, чуть сказочная, с лёгким налётом ретро-приключений.
- **Перспектива:** статичные «открытки» локаций, как в классических point-and-click (Machinarium, Botanicula, Night in the Woods).
- **Палитра:** глубокие тёплые тени (тёмно-коричневый, бордовый, фиолетово-синий) + акценты тёплого света (янтарный, медовый, бирюзовый огонёк ламп).
- **Свет:** один-два источника на сцену, мягкие градиенты, без жёстких теней.
- **Линия:** видимая, неровная, «ручная», без идеальных векторов.
- **Текстура:** лёгкая зернистость бумаги, едва заметная.

## UI
- Шрифт: гуманистический с засечками для текста писем, рукописный для подписей.
- Кнопки — стилизованные печати и почтовые штампы.
- Курсор/индикатор тапа — светлячок или конверт.

## Звук (опционально)
- Эмбиент подземелья: капли, тиканье часов, далёкие шаги.
- Короткие «фолк»-мотивы аккордеона и колокольчиков в локациях.
